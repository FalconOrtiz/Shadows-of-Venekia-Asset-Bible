## Map System (Non-Repeating Traversal)

See `14_MapSystem/MAP_RULES.md`

Key principle:
- Each biome has 8–12 unique base tiles + edge/transition variants
- Autotile / Wang tileset logic recommended
- Biome transition corridors
- Dungeon rooms use modular pieces so long runs never look identical
- Seed-based placement + weighted random + no-repeat window of last 6 tiles

## How to use with Grok Build / Runtime

1. Load StyleBible as reference for any new generation
2. Characters are front-view idle ready; generate walk/attack/cast frames from them
3. HUD bars are ready for Canvas 2D
4. Tilesets are designed to be sliced into 32×32 or 48×48
