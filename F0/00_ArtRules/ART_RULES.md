# Shadows of Venekia – Art Rules (Imagine Consistency) F0

1. **Character combat resolution**: 256–512 px height (legible at 390px mobile and desktop).
2. **Scene background**: 1920×1080 (16:9) with clear ground plane / floor zone for character placement.
3. **UI**: atlas or loose pieces with padding + stable names.
4. **Style**: pixel art 2D limpio (clean modern pixel / idle-RPG readable). Not ultra-crunchy extreme; clear silhouettes, limited palette, soft AA ok at edges.
5. **Each important skill**: at least icon 64/128 + 1 VFX cast/impact.
6. **Palette locked**: deep charcoal blacks, blood crimson, toxic green, molten orange, cold cyan, desaturated gold. Seeder corruption (glowing veins, liquid).
7. **Camera**: 3/4 or front for combat characters; clear ground zone for placement.

## F0 Acceptance
- GitHub commit with tree + MANIFEST
- Bases: Warrior + Hunter + Mage
- ≥1 Zone (1920×1080 clear ground)
- Base HUD
